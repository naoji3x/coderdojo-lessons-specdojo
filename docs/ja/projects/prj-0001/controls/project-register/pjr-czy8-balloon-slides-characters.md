# PJR-CZY8 第2回のスライドに案内役と考え方ごとのキャラクターを入れる

## 1. 概要

[[prj-0001:pjr-6g9t-balloon-slides-design|PJR-6G9T]] で整えた第2回（風船割りゲーム）の `slides.md` の各ページに、学校の授業らしいキャラクターを入れる。キャラクターは、ページごとに意味があり、全体で一貫した決まりに従って置く。

対象は宣言済みの `coderdojo-lessons` リポジトリの `courses/scratch-basic/lessons/020-balloon-game/slides.md`（必要なら同じディレクトリの `style.css`）。キャラクターは、テーマ `neversink` に含まれる部品を使う（`node_modules/slidev-theme-neversink/docs/components/kawaii.md`）。ライセンスは MIT の react-kawaii を移植したもので、外部の画像や新しいパッケージは使わない。

### 1.1. 配役（利用者と合意済み）

「案内役は1人、考え方ごとに担当が1人」とする。

| 役                   | 部品              | 色   | 意味づけ                                       | 出てくるページ                              |
| -------------------- | ----------------- | ---- | ---------------------------------------------- | ------------------------------------------- |
| 案内役「ねこ先生」   | `Cat`             | 灰色 | 授業を進める先生役。場面に合わせて表情が変わる | 全ページ（右下に小さく）                    |
| 変数「記録係」       | `Backpack`        | 橙   | 得点をしまっておく入れ物                       | 「今日使う4つの考え方」、1. 得点の2枚       |
| 乱数「びっくり係」   | `Planet`          | 緑   | どこに出るか分からない、宇宙のように広い場所   | 「今日使う4つの考え方」、2. 乱数の2枚       |
| クローン「コピー係」 | `IceCream`（3つ） | 黄橙 | 同じものが増える                               | 「今日使う4つの考え方」、3. クローンの2枚   |
| メッセージ「合図係」 | `SpeechBubbleGuy` | 黄   | 合図を伝える                                   | 「今日使う4つの考え方」、4. メッセージの2枚 |

ねこ先生の表情（`mood`）は、場面で使い分ける。

| 場面                                     | 表情         |
| ---------------------------------------- | ------------ |
| 表紙・今日のめあて                       | `excited`    |
| 完成見本・見つけるヒント                 | `happy`      |
| 作り方の説明（区切りと説明のページ）     | `blissful`   |
| ここまでできたら標準完成・発展ミッション | `lovestruck` |
| うまくいかないときは                     | `shocked`    |
| ふりかえり                               | `blissful`   |

### 1.2. 配置の決まり

- ねこ先生は、すべてのページで右下の同じ位置に、同じ大きさで置く。本文・ブロックの図・吹き出し・ページ番号に重ならない。
- 考え方の担当は、そのページの見出しの横か区切りの見出しの近くに置き、色は PJR-6G9T で決めた考え方の色（変数は橙、乱数は緑、クローンは黄橙、メッセージは黄）に合わせる。
- 「今日使う4つの考え方」では、4枚のカードそれぞれに担当を1人ずつ置く。
- Scratch のネコ（Scratch Cat）は Scratch の商標のため、似せない。ねこ先生は橙ではなく灰色にする。
- 色の付いた背景・ダークモードには戻さない（`colorSchema: light` と `color: white` を保つ）。

## 2. 完了条件

- 1.1 の配役と表情、1.2 の配置の決まりに従って、全17枚にキャラクターが置かれている。
- キャラクターが本文・ブロックの図・吹き出し・ページ番号に重ならず、文字が読みにくくなっていない。
- 14枚目「ここまでできたら標準完成！」で、吹き出しが上のカードに近すぎる問題が直っている（PJR-6G9T の残課題）。
- ブロックの図、スライドの構成、本文、「実機で確かめる」の印は変えない。区切りの直後に空行を入れない、ブロックの図の元は `text` のコードブロックで書く、という書き方を守る。
- 外部の画像や新しいパッケージを追加していない。
- `npx prettier --check`（`.prettierrc` の設定のまま）と `npx slidev build` が成功し、Slidev の解析器で全17枚の `layout` が効いている。`dist/` と `node_modules/` は commit しない。
- 見た目は、統合のあとに orchestrator が PNG（ライトモードとダークモード）で確かめ、最後に利用者が開発サーバーで確かめる。
- 対応結果に、配置のしかたと、ほかの回へ広げるときの注意を書く。結果の要約・申し送りは1項目を短い文にし、長いパスやコマンドは文と分けて書く。
