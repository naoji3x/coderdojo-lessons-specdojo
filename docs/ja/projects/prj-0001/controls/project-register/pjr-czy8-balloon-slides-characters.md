# PJR-CZY8 第2回のスライドに案内役と考え方ごとのキャラクターを入れる

## 1. 概要

[[prj-0001:pjr-6g9t-balloon-slides-design|PJR-6G9T]] で整えた第2回（風船割りゲーム）の `slides.md` の各ページに、学校の授業らしいキャラクターを入れる。キャラクターは、ページごとに意味があり、全体で一貫した決まりに従って置く。

対象は宣言済みの `coderdojo-lessons` リポジトリの `courses/scratch-basic/lessons/020-balloon-game/slides.md`（必要なら同じディレクトリの `style.css`）。キャラクターは、テーマ `neversink` に含まれる部品を使う（`node_modules/slidev-theme-neversink/docs/components/kawaii.md`）。ライセンスは MIT の react-kawaii を移植したもので、外部の画像や新しいパッケージは使わない。

### 1.1. 配役（利用者と合意済み）

「案内役は1人、考え方ごとに担当が1人」とする。

| 役                   | 部品              | 色   | 意味づけ                                       | 出てくるページ                              |
| -------------------- | ----------------- | ---- | ---------------------------------------------- | ------------------------------------------- |
| 案内役「ねこ先生」   | `Cat`             | 灰色 | 授業を進める先生役。場面に合わせて表情が変わる | 全ページ（右下に小さく）                    |
| 変数「記録係」       | `BackPack`        | 橙   | 得点をしまっておく入れ物                       | 「今日使う4つの考え方」、1. 得点の2枚       |
| 乱数「びっくり係」   | `Planet`          | 緑   | どこに出るか分からない、宇宙のように広い場所   | 「今日使う4つの考え方」、2. 乱数の2枚       |
| クローン「コピー係」 | `IceCream`（3つ） | 黄橙 | 同じものが増える                               | 「今日使う4つの考え方」、3. クローンの2枚   |
| メッセージ「合図係」 | `SpeechBubbleGuy` | 黄   | 合図を伝える                                   | 「今日使う4つの考え方」、4. メッセージの2枚 |

ねこ先生の表情（`mood`）は、場面で使い分ける。

| 場面                                     | 表情         |
| ---------------------------------------- | ------------ |
| 表紙・今日のめあて                       | `excited`    |
| 完成見本・見つけるヒント                 | `happy`      |
| 作り方の説明（区切りと説明のページ）     | `blissful`   |
| ここまでできたら標準完成・発展ミッション | `lovestruck` |
| うまくいかないときは                     | `shocked`    |
| ふりかえり                               | `blissful`   |

### 1.2. 配置の決まり

- ねこ先生は、すべてのページで右下の同じ位置に、同じ大きさで置く。本文・ブロックの図・吹き出し・ページ番号に重ならない。
- 考え方の担当は、そのページの見出しの横か区切りの見出しの近くに置き、色は PJR-6G9T で決めた考え方の色（変数は橙、乱数は緑、クローンは黄橙、メッセージは黄）に合わせる。
- 「今日使う4つの考え方」では、4枚のカードそれぞれに担当を1人ずつ置く。
- Scratch のネコ（Scratch Cat）は Scratch の商標のため、似せない。ねこ先生は橙ではなく灰色にする。
- 色の付いた背景・ダークモードには戻さない（`colorSchema: light` と `color: white` を保つ）。

- 14枚目「ここまでできたら標準完成！」で、吹き出しが上のカードに近すぎる問題が直っている（PJR-6G9T の残課題）。
- ブロックの図、スライドの構成、本文、「実機で確かめる」の印は変えない。区切りの直後に空行を入れない、ブロックの図の元は `text` のコードブロックで書く、という書き方を守る。

- 対応結果に、配置のしかたと、ほかの回へ広げるときの注意を書く。結果の要約・申し送りは1項目を短い文にし、長いパスやコマンドは文と分けて書く。

## 4. 対応結果

- 全17枚の右下に、同じ大きさ・位置の灰色の案内役「ねこ先生」を置き、場面に合わせて表情を切り替えた。
- 4つの考え方の一覧と各説明の2枚に、色と役割をそろえた担当キャラクターを見出し側へ置いた。
- 14枚目は右下に案内役の余白を確保し、吹き出しをカードから離した。
- ほかの回へ広げるときも、案内役の座標・大きさと考え方の色を共通の決まりとして使う。

### 4.1. 中断後に orchestrator が直したこと

1回目の実行は、実装役が確かめている途中で Codex の利用上限に達して止まった。
orchestrator が PNG で確かめ、次の3点を worktree の中で直した。

- ねこ先生が全ページで表示されなかった。
  原因は `v-drag` の横位置 1160 が、スライドの横幅 980 の外だったこと。
  `v-drag` をやめ、`style.css` の `.teacher-cat` で右下に固定した。
- 表紙では、ねこ先生が `:: note ::` の枠の中にあり、文字に重なっていた。
  ねこ先生を本文側へ移した。
- 変数のリュックが表示されなかった。
  テーマの部品名は `BackPack` のため、`<Backpack>` を `<BackPack>` に直した。

再開後の実装役への申し送り:

- 上の修正は利用者の承認を得たものである。キャラクターの配置・大きさ・部品名は変えない。
- 完了条件の確かめ（prettier・build・解析器）と、対応結果の更新だけを行う。
- PNG での見た目は orchestrator がライト・ダークの両方で確かめ済みである。
- 結果ファイルは markdownlint の MD013（1行80文字）に合わせ、長い行は折り返す。

### 4.2. 統合後に orchestrator が直したこと

利用者の依頼で、統合後のスライドを orchestrator が直接直した。
coderdojo-lessons の `feature/prj-0001/balloon-slides-font-size` で
2つの commit（`c463d69`・`aa3e262`）にし、develop へ merge した（`c2f5b3c`）。

- 本文・吹き出し・付箋・カード・完成チェック・ブロック図の見出しの文字を大きくした。
  本文の段落と箇条書きは 1.2rem から 1.8rem にした。
- 見出しはテーマが基準の文字サイズから em で決めるため、基準は 1.2rem のまま変えていない。
  基準を上げると見出しまで大きくなり、表紙・3枚目・8枚目の見出しが折り返した。
- ねこ先生の大きさを 72 から 112 にした。
  利用者の依頼で一度 144 にしたが、大きすぎるとの指摘を受けて 112 にした。
- 大きくしたことで起きたはみ出しと重なりを直した。
  9枚目の箇条書きの間隔と、5枚目のカードの余白を詰めた。
  14枚目の吹き出しの最大幅を 720px に広げた。
- 章の扉で、見出しの下線と説明文の間を 1.4rem あけた。
- 2枚目以降のページ設定が setext 形式の見出しと判定され、
  markdownlint の MD003 と MD022 の警告が出ていた。
  slides.md の先頭に注釈を置いてこの2つの規則だけを止め、ガイドの 3.1 に理由を書いた。

確かめたこと:

- ライト・ダークの両方で全17枚を PNG にし、はみ出しと重なりがないことを確かめた。
- prettier と markdownlint が通り、Slidev の解析器で全17枚の `layout` が効いている。

ほかの回へ広げるときの注意:

- 文字を大きくするときは `.slidev-layout` の基準を変えず、段落・箇条書き・部品の文字を指定する。
- 2列のページは、文字を大きくすると折り返しが増え、下にはみ出しやすい。
- 新しい slides.md には、ガイドの 3.1 に従って markdownlint の注釈を置く。
