# PJR-AF5N 第2回の背景の用意をメッセージの段階へ移し、背景の追加方法と「すべてを止める」の色を直す

## 1. 概要

020-balloon-game のスライドと指導案で、背景「開始」「クリア」の追加と「背景を [開始] にする」を得点の段階（14・15P）からメッセージの段階の最初へ移し、背景の追加方法を文章で解説する。18P の「すべてを止める」を制御の色で表示されるように直し、背景に「クリア」の文字を描く手順を標準完成の後・発展ミッションの前に余裕があれば行う内容として加える

## 2. 入力

- 対象は coderdojo-lessons の courses/scratch-basic/lessons/020-balloon-game の slides.md と lesson-plan.md
- 15P のステージのコードにある「背景を [開始 v] にする」と、14P の背景「開始」の作成は、得点の段階で背景を扱うと時間がかかるため、メッセージの段階（4. 10点でクリアにしよう）の最初へ移す。背景「開始」「クリア」の追加をそこでまとめて行い、「背景を [開始 v] にする」もそのときに旗のスクリプトへ足す
- 背景の追加方法の解説を加える。解説は文章だけとし、スクリーンショットは使わない
- 18P の「すべてを止める」のブロックが制御の色で表示されていない。scratchblocks の日本語辞書では `CONTROL_STOP` が " %1" で、ブロック全体がドロップダウンのため、角かっこなしの記法では認識されていない見込み
- 背景に「クリア」の文字を描く手順は、途中で行うとつまずく児童が多いため、時間に余裕があれば行う内容として「ここまでできたら標準完成！」の後・発展ミッションの前に置く（A案）
- 指導案もスライドに合わせて直す（基本制作3・4、時間配分、支援、背景を描くことは求めないとする記述など）
- 第1回（010-chase-game）のスライドにも同じ記法の「すべてを止める」が2か所あるが、この項目の範囲外とする

## 3. 完了条件

- **背景の用意の移動**：スライドの得点の段階（現在の14・15ページ）から、背景「開始」の作成と `背景を [開始 v] にする` を取り除き、得点の準備のページは変数「得点」の作成だけにする。メッセージの段階（4. 10点でクリアにしよう）の最初で背景「開始」「クリア」を続けて追加し、ステージの旗のスクリプトに `背景を [開始 v] にする` を足す流れにする。ブロック図は、その段階で足すブロックが分かる形にする。
- **背景の追加方法の解説**：ステージを選ぶ → 「背景を選ぶ」から背景ライブラリを開いて選ぶ → 「背景」タブで名前を変える、という手順を文章で示す。スクリーンショットは使わない。未確認の Scratch の操作名は断定しない。
- **「すべてを止める」の色**：メッセージのページの `すべてを止める` が、scratchblocks で制御の色で表示されるように記法を直す。
- **「クリア」の文字を描く手順**：「ここまでできたら標準完成！」の後、発展ミッションの前に、時間に余裕があれば背景「クリア」に文字を描く手順を置く。描く方法（テキストツールなど）は文章で示す。標準完成形には含めない。
- **指導案の整合**：`lesson-plan.md` の基本制作3・4の記述、準備、5章の時間配分の表と進め方、評価、声かけとつまずき対応、まとめを、上の流れに合わせる。「背景を自分で描くことは求めない」という記述は、文字入れを余裕があれば行う内容として扱う形に直す。時間配分の合計（45分）は変えない。
- **変えないもの**：乱数・クローンの段階、最低完成形と標準完成形のブロックの内容、他の回の教材、共有の lint 設定は変えない。
- **検査**：作業を終える前に、変更したファイルについて `coderdojo-lessons` の Prettier（`slides.md` は `slidev` parser）・markdownlint・Slidev build（`npx slidev build`）を通す。
- **表示の確認**：exec の sandbox で Slidev の PNG 書き出しができない場合は、統合後に orchestrator が `npx slidev export courses/scratch-basic/lessons/020-balloon-game/slides.md --format png` で全ページを書き出し、変えたページの文字の切れ、案内役との重なり、「すべてを止める」の色を目視で確かめる。
- 実施内容と検証結果を個票の対応結果に記録する。登録簿の状態、result、設定ファイルは変更しない。
