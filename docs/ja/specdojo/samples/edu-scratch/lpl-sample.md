# 宇宙船を着陸させよう

活動別指導案の完成例（仮想設定）

これは実施記録ではなく、学習用に設定した 1 回分の指導案例である。題材、対象、時間、端末環境はこの例だけの仮定であり、ほかの活動の標準を定めるものではない。

## 1. 授業の概要

### 1.1. 対象と所要時間

Scratch の基本操作と、イベント、繰り返し、座標、条件分岐、当たり判定を経験した小学 5・6 年生を想定し、所要時間は 40 分とする。

### 1.2. テーマ

方向キーで宇宙船を動かし、着陸地点に重なると着陸成功を知らせる「宇宙船を着陸させよう！」を作る。

### 1.3. 授業のねらい

- 開始時に作品の状態をそろえ、座標の変化を使って宇宙船を動かす。
- 繰り返しと条件分岐で、宇宙船が着陸地点に重なったかを確かめ、成功時の動作へつなげる。
- 旗を押して始め直し、1 つの変更ごとに動かして、意図した動きになったかを説明する。

### 1.4. 使用する主な機能と作品での役割

| 機能                       | 作品での役割                               | 対応するねらい           |
| -------------------------- | ------------------------------------------ | ------------------------ |
| 旗での開始                 | 宇宙船の位置と成功表示を開始時の状態に戻す | 状態をそろえて始める     |
| 方向キーの入力と座標の変更 | 宇宙船を上下左右へ動かす                   | 座標の変化を使う         |
| 繰り返し                   | 着陸地点に重なったかを続けて確かめる       | 動作を繰り返して確かめる |
| 条件分岐と接触判定         | 着陸成功のときだけ表示を変え、操作を終える | 成功時の動作へつなげる   |

## 2. 授業の位置づけ

この例は、コース計画の最終回で示す「既習内容を組み合わせて改造し、発表する」という考え方を、仮想の自由制作ワークショップに具体化したものである。前の活動で扱ったイベント、繰り返し、座標、条件分岐、当たり判定を、宇宙船を着陸させる 1 つの作品に組み合わせる。

コース計画では最終回の後に次の授業は設定されていない。この仮想例では、保存した作品を次の鑑賞・振り返りの材料にするが、実際のコース計画や次回の内容を変更するものではない。

## 3. 完成する作品

宇宙船は旗を押すと画面の左上寄りの開始位置に戻る。学習者は方向キーで宇宙船を動かし、着陸地点に重ねる。成功すると成功表示に変わり、宇宙船はそれ以上動かない。もう一度旗を押すと、成功表示を消し、宇宙船を開始位置に戻して再開できる。

### 3.1. 最低完成形

- 旗を押すと宇宙船が決めた開始位置に戻る。
- 方向キーで宇宙船を上下左右に動かし、どの座標の変化がどの方向の移動に対応するかを説明できる。

### 3.2. 標準完成形

- 宇宙船が着陸地点に重なったかを繰り返し確かめる。
- 重なったときだけ成功表示に変え、宇宙船の操作を終える。
- 旗を押すと開始位置と成功前の表示に戻り、もう一度着陸に挑戦できる。

### 3.3. 発展形

- 着陸地点の位置、宇宙船の移動量、開始位置のいずれかを変え、難しさがどう変わるかを説明する。
- 宇宙船の軌跡が分かる表示または成功時の見た目を 1 つ工夫し、標準完成形の開始・成功・再開が保たれることを確かめる。

## 4. 事前準備

### 4.1. 教師用の完成見本と実機確認

教師用の完成見本は、開始、宇宙船の移動、着陸成功、操作終了、旗による再開までを続けて確認する。開始時には宇宙船の位置と成功表示を必ず初期状態へ戻す。

授業前に、投影端末と学習者用端末で、方向キー入力、座標の変更、接触判定、保存と再読込が使えることを確認する。Scratch の画面上のブロック名や端末ごとの操作は、この実機確認で使用環境に合わせて確かめる。未確認の名称や挙動を、この例の確定事項にはしない。

### 4.2. 開始用プロジェクトと素材

この仮想例では、開始用プロジェクトに宇宙船の素材、着陸地点の素材、背景だけを用意する。宇宙船の制御、成功の判定、成功表示、再開の処理は学習者が作る。途中段階のプロジェクトは、この例では配らず、遅れた学習者には教師用完成見本の画面共有と最低完成形へ戻る支援を使う。

教師は、素材が投影画面と学習者用端末で判別できる大きさか、開始位置と着陸地点が重ならないかも確認する。素材の種類や開始用プロジェクトの範囲は、実施時の端末環境と学習者の経験に応じて決める。

## 5. 授業の流れ

| 時間      | 学習内容・活動                                                            | 指導上の留意点                                                                          |
| --------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 0〜4 分   | 導入：完成見本を動かし、開始、着陸成功、再開で何が変わるかを観察する      | 「旗を押した直後」と「着陸した直後」の宇宙船と表示を比べる。                            |
| 4〜11 分  | 基本制作 1：開始時の宇宙船の位置を決め、方向キーで上下左右に動かす        | 教師の提示後、学習者が操作し、旗から動かす。座標の変化を 1 つだけ変えて方向を確かめる。 |
| 11〜20 分 | 基本制作 2：着陸地点への接触を繰り返し確かめ、成功時だけ表示を変える      | 宇宙船を着陸地点の外と中へ動かして比較し、条件がいつ成り立つかを確認する。              |
| 20〜29 分 | 基本制作 3：成功後は宇宙船の操作を終え、旗で開始状態へ戻せるようにする    | 成功、停止、再開を順に試す。再開時に成功表示が残る場合は、開始時の状態を確認する。      |
| 29〜35 分 | 発展または合流：標準完成形を仕上げるか、位置・移動量・表示を 1 つ改造する | 標準完成形に届かない学習者は、発展よりも成功と再開の処理を優先する。                    |
| 35〜40 分 | まとめ：保存し、隣の学習者に 1 回動かして見せ、工夫と直した点を伝える     | 保存できたことを確認してから見せ合う。公開共有は行わない。                              |

区間の合計は 40 分であり、授業の所要時間と一致する。

## 6. 進め方と進度差への対応

基本制作では、教師が 1 つの動作を投影して示し、学習者が自分の端末で作り、旗から動かして確認してから、関連する値または表示を 1 つ変えて試す。この順序は、この仮想例の宇宙船ゲームのための進め方である。

先にできた学習者は、着陸地点の位置や移動量を変え、難しさの変化を説明する。遅れた学習者は、宇宙船を動かす最低完成形をまず作り、教師用完成見本の開始状態と自分の画面を比べる。時間が不足した場合は、発展と見せ合いの時間を短くし、開始位置への初期化と方向キーでの移動を残す。残り時間と到達状況に応じて、着陸成功の判定、操作の終了、旗による再開という標準完成形に取り組む。

## 8. 声かけの例とつまずきへの対応

| 場面     | 声かけの例                                                         | つまずきへの対応                                                                     |
| -------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 開始     | 「旗を押した直後、宇宙船と成功表示はどうなっているかな。」         | 前回の成功状態が残るときは、開始時に戻すべき位置と表示を完成見本と並べて確認する。   |
| 移動     | 「右へ動かしたいとき、どちらの座標を変えるとよいかな。」           | 1 回の入力でどの方向へ動くかを観察し、座標の変更を 1 つに絞って試す。                |
| 着陸判定 | 「着陸地点の外と中で、表示はいつ変わるかな。」                     | 宇宙船を着陸地点の外と中へ交互に動かし、判定する条件と確認の繰り返しを分けて見直す。 |
| 成功後   | 「成功したあと、もう動かさないためには何を終える必要があるかな。」 | 成功時の表示、操作の終了、旗での再開を順に動かし、どの状態でずれたかを確認する。     |
| 発展     | 「変えるのは 1 つだけにすると、何が変わったか説明できるかな。」    | 標準完成形が未到達なら改造を止め、成功と再開ができる状態へ戻る。                     |

## 9. まとめと次回へのつなぎ

まとめでは、座標で動きを決め、条件で成功の動作を選び、旗で状態を戻すことで、何度も試せる作品になることを振り返る。保存は、鑑賞・振り返りで作品をもう一度動かすために必要とする。この例では、35〜40 分に学習者が自分の端末へ `.sb3` 形式で保存し、教師は授業前の実機確認で保存先と再読込の手順を確かめる。

共有は隣の学習者に端末画面を見せる範囲にとどめ、オンラインへの公開や外部への送信は行わない。コース計画上は最終回のため、次の授業を予告せず、保存した作品を後日の鑑賞・振り返りで使う想定とする。
